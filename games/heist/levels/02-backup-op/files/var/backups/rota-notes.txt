backup rota -- handover notes
=============================

The nightly agent drops a tarball in /var/backups so someone can eyeball it
before it goes to tape. Nobody has ever eyeballed one. It does NOT clean up
after itself, so whole home directories sit there in the clear, keys and
all. I have raised it twice.

On-call needs to see the agent logs, so they have their own account:

    {{ .User "ops-oncall" }} / {{ .Password "ops-oncall" }}

Rotate it when the rota changes. (It has not been rotated.)
